# 프렙 카페 운영관리

현재 구현 범위는 EPIC 1~3의 판매·재고·비용 관리, 일·월 수익성·손익, 전체 JSON 백업·복원입니다. 자동 검사 65개와 로컬 브라우저 검사를 통과했습니다. 사용자 확인과 Vercel 실제 배포는 대기 상태입니다. 코드 저장소는 https://github.com/ehdals961107-jpg/coffeecoyange2 입니다.

Node.js 24에서 `npm ci`, `npm run dev`로 실행합니다. 검사는 `npm run test`, `npm run typecheck`, `npm run build`입니다.

기록은 동일 주소·브라우저 프로필의 IndexedDB에 저장됩니다. 프로그램을 재시작해도 샘플을 추가하지 않습니다. 브라우저 데이터를 지우면 기록이 사라집니다. 백업 화면에서 전체 JSON을 내려받아 안전한 개인 폴더에 보관하세요. 복원은 파일 검증·전체 대체 확인 후 실행됩니다. 실제 운영 자료를 GitHub나 공개 파일에 넣지 마세요.

초기 파일은 제공된 가상 샘플을 그대로 복사한 자료입니다. 메뉴·가격은 원본을 사용하며 공개용 실거래 자료가 아닙니다. 정책과 검사 결과는 docs 문서를 참고하세요.

Vercel은 `vercel.json`의 Vite / `npm run build` / `dist` 구성을 사용합니다. 기본 배포 주소를 정한 후 계속 같은 주소를 사용하세요. 로컬·미리보기·운영 주소의 브라우저 기록은 공유되지 않으므로 주소를 옮길 때 백업 후 복원해야 합니다. GitHub 업로드는 완료했습니다. Vercel 프로젝트의 계정 연결과 실제 배포 확인이 남아 있습니다. 카페 영업용 요금제 조건은 TRD를 참고하세요.
